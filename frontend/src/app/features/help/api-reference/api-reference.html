Decision engine REST API

Everything the app does goes through this JSON API, so you can call it from scripts, Postman or other systems. Errors are application/problem+json.

Base URL {{ baseUrl }}

Authentication

Every /api call needs credentials, except login and health. Use HTTP Basic with a username and password (curl -u user:password), or a Bearer token from POST /api/auth/login. The caller recorded in the audit trail is always the authenticated account; an X-User header is ignored.
